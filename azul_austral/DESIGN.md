## Brand & Style

The design system projects academic excellence, energetic student agency, and civic pride for the Universidad de Chile community. It translates historical institutional gravitas into a contemporary digital ecosystem built for active student life, cross-campus event discovery, and collective participation.

The visual direction merges **Corporate / Modern** structure with energetic university cues:
- **Tone & Atmosphere:** Democratic, spirited, trustworthy, and organized. It avoids institutional stiffness by introducing vivid chromatic accents and high-legibility touchpoints.
- **Visual Style:** Modern clean surface architecture, disciplined structural alignment, soft-tinted borders, and warm tactile micro-interactions.
- **Target Audience:** Undergraduates, postgraduates, academic societies, faculty secretariats, and campus organizers across distributed campuses (Beauchef, JGM, FEN, Medicina, etc.).

## Colors

The chromatic identity centers on the historic institutional deep blue, contrasted with energetic amber/ochre and a decisive action-oriented cyan.

### Functional Palette Mapping
- **Primary (`#002B7A`):** Anchors global navigation, prominent heading accents, key brand containers, and active navigation items.
- **Secondary (`#D97706` / `#F59E0B`):** University amber for high-priority student badges, featured events, deadline alerts, bookmark highlights, and star ratings.
- **Tertiary (`#0284C7`):** Direct interaction signals, interactive links, calendar indicators, and active selection filters.
- **Neutral System:**
  - Canvas Background: `#F8FAFC` (Slate 50)
  - Card & Container Surface: `#FFFFFF`
  - Subtle Borders & Rules: `#E2E8F0` (Slate 200)
  - Secondary Text / Subtitles: `#475569` (Slate 600)
  - Primary Text & Structural Headings: `#0F172A` (Slate 900)

### Status & Event Taxonomy Tokens
- **Modality Badges:**
  - *Presencial:* Deep emerald surface (`#ECFDF5`), border (`#A7F3D0`), text (`#065F46`).
  - *Online / Remoto:* Sky surface (`#F0F9FF`), border (`#BAE6FD`), text (`#0369A1`).
  - *Híbrido:* Violet surface (`#F5F3FF`), border (`#DDD6FE`), text (`#5B21B6`).
- **Publication Lifecycle:**
  - *Borrador:* Slate surface (`#F1F5F9`), text (`#475569`).
  - *Pendiente:* Amber surface (`#FEF3C7`), text (`#92400E`).
  - *Publicado:* Emerald surface (`#D1FAE5`), text (`#047857`).
  - *Importado:* Indigo surface (`#EEF2FF`), text (`#3730A3`).

## Typography

Plus Jakarta Sans is utilized across all typographic levels. Its wide geometric apertures, balanced vertical proportions, and contemporary humanist accents maintain optimal legibility on dense schedule feeds, technical event agendas, and handheld mobile devices.

- **Display & Section Headers:** High-contrast weights (`700` and `800`) with tight tracking for headlines, dates, and campus banners.
- **Body:** Standardized at `14px` and `16px` with neutral dark slate (`#0F172A`) for high contrast against pure white cards and tinted canvases.
- **Data Labels & Badges:** `label-caps` in uppercase format provides immediate clarity for event modalities, faculty stamps, and date numerals.

## Layout & Spacing

A balanced fluid layout anchored on an 8pt baseline rhythm:

- **Desktop (1024px+):** 12-column responsive grid with `1.5rem` (24px) gutters, maximum container width capped at `1280px` for optimal reading scan line. Side navigation expands to a structural sidebar.
- **Tablet (768px - 1023px):** 8-column layout with `1.25rem` gutters. Cards shift into two-column configurations.
- **Mobile (< 768px):** Single-column stack with `1rem` (16px) margins and gutters. Global actions dock into an ergonomic bottom navigation bar.
- **Rhythm Rules:** Inner card padding defaults to `space-md` (16px) on mobile and expands to `space-lg` (24px) on desktop event cards.

## Elevation & Depth

Visual hierarchy uses **low-contrast outlines combined with ambient multi-stop drop shadows**. The design keeps depth crisp, clean, and glare-free under varied lighting environments.

- **Flat Layer (Canvas):** Pure `#F8FAFC`, zero shadow.
- **Elevation 1 (Cards, Feed Tiles, Inactive Chips):** Solid `#FFFFFF` background, paired with a subtle structural border: `1px solid #E2E8F0`. Shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Elevation 2 (Card Hover, Dropdown Menus, Active Modals):** `0 10px 15px -3px rgba(0, 43, 122, 0.07), 0 4px 6px -4px rgba(0, 43, 122, 0.04)`. Ambient tinting borrows subtly from institutional blue to avoid dirty gray effects.
- **Elevation 3 (Floating Action Buttons, Mobile Bottom Sheets):** `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.06)`.

## Shapes

The interface embraces a modern, friendly curvature without drifting into non-functional excess:

- **Base Radius (`0.5rem` / 8px):** Input fields, interactive filter chips, badges, and segmented toggles.
- **Container Radius (`1rem` / 16px):** Primary event cards, module panels, calendar date blocks, and desktop dialog windows.
- **Outer Shell Radius (`1.5rem` / 24px):** Mobile bottom sheets, hero banner showcases, and floating search headers.
- **Full Pill (`9999px`):** Avatar indicators, faculty tags, and compact modality status pills.

## Components

### Event Card Structure
- **Container:** Pure `#FFFFFF` surface, `border: 1px solid #E2E8F0`, rounded at `1rem`, subtle elevation 1.
- **Calendar Date Stamp:** Nested in the upper left or right corner. Top block in `#002B7A` with 3-letter month in bold caps (`label-caps`, white), bottom block in `#F8FAFC` with the numeric day (`20px`, bold, `#0F172A`).
- **Body & Metadata:** Event title (`headline-sm`), faculty chip, venue/online indicator, and time stamp paired with micro-icons.
- **Action Footers:** Flex container with interactive bookmark icon (`#D97706` when active), star rating preview (`#F59E0B`), and primary "Ver detalle" cyan button.

### Badges & Faculty Chips
- **Faculty Chips:** Soft background using `#F1F5F9`, border `#CBD5E1`, text `#334155`. On hover or active filter state, background changes to deep blue `#002B7A` with pure white text.
- **Modality Badges:** Small caps text, height `24px`, padding `0 10px`, fully rounded (`rounded-full`). Distinct semantic tints for Presencial (Green), Online (Sky), and Híbrido (Purple).

### Buttons
- **Primary:** Filled `#002B7A` with white text, font `label-lg`, hover color `#0D3B8E`, active state slightly inset.
- **Action / Interactive (`Cyan`):** `#0284C7` background, hover `#0369A1`, used for RSVPs, registrations, and urgent participation CTAs.
- **Secondary / Outlined:** `border: 1.5px solid #002B7A`, text `#002B7A`, transparent background, hover `#F0F4FF`.
- **Icon / Favorite Toggle:** Ghost button holding a geometric bookmark or heart outline. When toggled, fills with amber `#F59E0B` and triggers a micro-scale bounce.

### Form Inputs & Selectors
- Background `#FFFFFF`, height `44px`, border `1.5px solid #E2E8F0`, corner radius `0.5rem`.
- Focus state: Border transitions to `#0284C7` with a subtle focus ring `0 0 0 3px rgba(2, 132, 199, 0.15)`.

### Rating Component
- Five-star interactive group with `#CBD5E1` unfilled state and `#F59E0B` filled state, accommodating half-star visual increments and micro tooltips.
